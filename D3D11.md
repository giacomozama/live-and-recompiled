# Direct3D 11 on Windows

Set `renderer = "d3d11"` in `settings.toml` to select the backend. The
`XBE_RENDERER=d3d11` environment variable overrides the setting for one launch.
Vulkan remains the default. If Vulkan initialization fails on Windows, the
runtime tries D3D11. The adapter must support Direct3D feature level 11.0.

Build with the Windows toolchain in [BUILDING.md](BUILDING.md). The Windows host
build includes the ImGui DX11 backend and links D3D11, DXGI and the system HLSL
compiler.

The backend uses the existing Xbox texture and vertex decoders, shader
translator, and interpolated draw replay. The render scale applies to both
dimensions of the displayed game picture, excluding black bars. The backend
uses the graphics menu's MSAA, SMAA, FSR 1.0, post-processing, lighting, fur and
water settings. HDR10 output requires a display with Windows HDR enabled.

Compiled shaders are saved in `d3d11-shaders-v1.bin` in the cache directory.
Previously unseen shaders can cause stalls during play. `XBE_PERF=1` enables
render timing in `logs/game.log`. Late resource reads are synchronous.
Swizzled and non-32-bit surface readback and gamma-ramp fidelity need additional
work.

The D3D11 smoke test compiles representative generated HLSL and exercises
point coordinates and depth/stencil reads on the GPU. From the repository root,
run the following with the project's Windows Zig toolchain.

```powershell
zig c++ -target x86_64-windows-gnu -mcpu=x86_64_v2 -std=gnu++20 -DNDEBUG -O2 `
  -I src/runtime tools/d3d11-shader-smoke.cpp src/runtime/gpu/shaders.cpp `
  -ld3d11 -ld3dcompiler_47 -o d3d11-shader-smoke.exe
.\d3d11-shader-smoke.exe
```

The device and swap-chain setup is adapted from sp00nznet's MIT-licensed
xboxrecomp. See [D3D11-NOTICE.txt](D3D11-NOTICE.txt).
